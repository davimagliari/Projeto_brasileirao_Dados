# Scripts

Esta pasta contém os scripts utilizados na Análise Exploratória de Dados (AED) do projeto.

## Arquivo

### analise_exploratoria.py

Script desenvolvido em Python para realizar a exploração inicial da base de dados do Campeonato Brasileiro. As principais análises realizadas são:

- Leitura e inspeção da base de dados;
- Verificação de valores nulos;
- Estatísticas descritivas dos gols;
- Frequência de resultados (mandante, visitante e empate);
- Média de gols por temporada;
- Cálculo da variância dos gols;
- Identificação de outliers por meio de boxplot;
- Ranking dos clubes com mais vitórias em casa;
- Geração de gráficos para apoio à interpretação dos dados.

Bibliotecas utilizadas:

- Pandas
- NumPy
- Matplotlib

O script utilizado neste projeto é o arquivo `analise_exploratoria.py`.
