# Projeto Aplicado I

## Análise de Desempenho de Clubes no Campeonato Brasileiro

Projeto desenvolvido na disciplina Projeto Aplicado I com o objetivo de analisar dados históricos do Campeonato Brasileiro Série A utilizando técnicas de Análise Exploratória de Dados (AED).

## Base de Dados

- Fonte: Kaggle
- Formato: CSV
- Registros: 6.460 partidas
- Variáveis: 9 colunas

---

## Principais Resultados

### Frequência de Resultados

- Mandante: 3.168 vitórias
- Empate: 1.740 partidas
- Visitante: 1.552 vitórias

Os resultados indicam vantagem para equipes que atuam em casa.

### Média de Gols

- Mandante: 1,48 gols por partida
- Visitante: 0,99 gols por partida

As equipes mandantes apresentam melhor desempenho ofensivo.

### Variância dos Gols

- Mandante: 1,43
- Visitante: 0,99

Os gols dos mandantes apresentam maior variabilidade.

### Clubes com Mais Vitórias em Casa

1. Atlético-MG – 190
2. Grêmio – 188
3. Flamengo – 182
4. São Paulo – 180
5. Internacional – 177
